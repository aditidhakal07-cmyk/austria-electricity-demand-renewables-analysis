# Austria Electricity Demand and Power-System Data Analysis

## Project Overview

This project presents an exploratory analysis of Austria's electricity demand and power-system data using Python and Jupyter Notebook.

The analysis uses historical hourly data from **Open Power System Data (2015–2020)** to investigate electricity consumption patterns, seasonal variations, peak demand, and relationships between electricity load and day-ahead market prices.

## Analysis and Visualizations

The notebook includes:

- **Multi-year demand trends:** Comparison of average and peak electricity load.
- **Seasonal demand patterns:** Monthly average electricity consumption.
- **Daily load profiles:** Hourly variations in electricity demand.
- **Weekday analysis:** Differences between weekday and weekend consumption.
- **Load distribution:** Statistical visualization of hourly electricity demand.
- **Electricity price analysis:** Relationship between day-ahead electricity prices and load.
- **Yearly comparisons:** Daily mean electricity load across different years.

## Tools and Libraries

Python, Jupyter Notebook, Pandas, Matplotlib, and Seaborn.
